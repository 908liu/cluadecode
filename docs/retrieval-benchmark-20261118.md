# 检索方案基准报告（2026-11-18）

- 索引版本：idx_c7e6b26977964649
- 对比方案：Dense、Hybrid（关键词 + 向量 + RRF）、Hybrid + Rerank（gte-rerank-v2）

## 结论

- Hybrid 相比 Dense：Recall@4、MRR 提升约 83.33 个百分点，拒答正确率提升 50 个百分点，模型均分提升 2.232 分。
- Hybrid + Rerank 相比 Hybrid：拒答正确率提升到 100%，评分覆盖率从 87.5% 提升到 100%；召回指标保持满分，平均耗时增加约 123 ms。
- 在该标准集上，Rerank 主要提升拒答稳定性和评分完整性，而不是召回排名；其收益需要在难评测集和长文档集上继续验证。
- 这组数据适合作为项目证明中的「检索方案对比基线」，但不能据此声称 Rerank 在所有场景均提升召回。

## 对比结论

- 公司制度集验证了 Hybrid 的核心收益：Recall@4 从 40% 提升到 100%，拒答正确率从 50% 提升到 100%。
- 难评测集是最能体现 Rerank 价值的非饱和场景：Rerank 将 Recall@4 从 88.24% 提升到 100%，MRR 从 39.71% 提升到 91.18%，NDCG@4 从 52.18% 提升到 93.49%。
- Rerank 将部分金标 chunk 从候选排序后部提升到前四位，但标准集和公司集的召回已经饱和，因此在简单集上差异不明显。
- Dense 在难集几乎无法召回有效资料（Recall@4 0、MRR 0、NDCG@4 0），说明只依赖向量检索不适合该项目的制度与流程问答。
